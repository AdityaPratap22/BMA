# BMA – Best Marketing Agency | Next.js 14+ Application

**BMA (Best Marketing Agency)** is a modern, ultra-fast, zero-plagiarism digital growth agency web application built from scratch using **Next.js 14 (App Router)**, **TypeScript**, and **Tailwind CSS**.

---

## 🎨 Theme & Visual Identity

Extracted from high-end terracotta & warm cream branding design:

- **Brand Logo**: `BMA` (Best Marketing Agency)
- **Background Base**: `#FDFBF7` (Warm Cream White)
- **Card Surface**: `#F7F3ED` / `#FAF6F0` (Soft Cream Beige)
- **Primary Brand / CTA**: `#9A481B` (Warm Terracotta Amber Brown)
- **Primary Hover**: `#793612` (Deep Terracotta)
- **Headings Font**: `Playfair Display` (Serif Google Font via `next/font/google`)
- **Body Font**: `Plus Jakarta Sans` (Sans-serif Google Font via `next/font/google`)

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js 18+ and npm installed.

### 1. Installation

Install all required dependencies:

```bash
npm install
```

### 2. Development Server

Run the development server locally:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application live.

### 3. Production Build & Test

To build the production-ready bundle and verify TypeScript/routing compilation:

```bash
npm run build
npm run start
```
